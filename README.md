# Deep-Learning-Assignment-2_23F-0848

CIFAR-10 image classification using a small Inception-style CNN.

The notebook includes baseline training, augmentation experiments,
a three-seed ablation study, error analysis, a grayscale test,
and test-time augmentation.

## How to run
Open Deep_Learning_Assignment_2_23F-0848.ipynb in Google Colab or Jupyter.
Install the required libraries and run the cells from top to bottom.
